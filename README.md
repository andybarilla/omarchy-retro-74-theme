# Retro 74 for Omarchy

A dark [Omarchy](https://omarchy.org/) theme inspired by 1974 automotive paint,
vinyl interiors, amber instrument panels, and warm parchment upholstery.

![Retro 74 preview](preview.png)

## Palette

| Role | Color | Hex |
|---|---:|---:|
| Background | Deep aubergine | `#180A29` |
| Raised surface | Rich purple | `#30144A` |
| Accent | Lime/chartreuse | `#B7D43D` |
| Selection | Plum vinyl | `#563272` |
| Foreground | Parchment | `#F2E7C9` |
| Orange | Burnt orange | `#D97A34` |
| Yellow | Mustard | `#D8AA3B` |
| Cyan | Muted teal | `#5EA89B` |

## Install

```bash
omarchy theme install https://github.com/andybarilla/omarchy-retro-74-theme.git
```

Then select **Retro 74** in the Omarchy theme switcher, or run:

```bash
omarchy theme set "Retro 74"
```
